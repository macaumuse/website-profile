Regional profile display:
- AU visitors see the Australian appointments without the Zhejiang University appointment or professor heading.
- CN, HK, MO and TW visitors retain the Zhejiang University profile and do not load the Australian appointments.
- Other recognised countries retain both sets of appointments.
- While geolocation is pending or unavailable, country-dependent appointments stay hidden; the page heading uses a neutral academic-profile label.
- Shared page metadata and portrait alternative text do not advertise a country-specific appointment.

Country detection uses Cloudflare's same-origin `/cdn-cgi/trace`. These are presentation rules for a public static website, not access controls on its files.
